# InkDock v0.1.0-alpha.6

- 修复离线后台朗读：独立mediaPlayback前台服务持有完整队列，通知/媒体会话控制，暂停从当前分片开头恢复；Home/锁屏不再依赖WebView继续下一段。
- 音频焦点丢失/耳机拔出暂停，停止清空队列并释放播放资源。
- 增加外部离线包安装与配置中心（官方来源/引擎模型管理/重新检测）。目前不是App内模型下载器。
- 修复更多动作后面板残留，导入取消返回不会留下更多遮罩。
- 云朗读进入后台会取消当前流程，未确认片段不发送；后台持续播放仅用于系统离线TTS。

以下能力沿用alpha.5：

- 新增已安装系统 TTS 引擎选择，按引擎保存离线中文音色，切换时取消旧朗读。
- 新增实验性 Qwen / MiniMax 原生配置、Android Keystore 加密密钥保存与删除、云音频播放。没有内置账号或密钥。
- 声明 INTERNET 权限；WebView 仍禁止网络。每次启动默认系统离线模式，保存配置不发请求。每个云片段发送前展示服务商、地址、模型、音色、完整文本及可能费用，需用户确认。
- 云确认窗口取消或返回不会发送该片段；点停止、进入后台或切换来源会停止当前任务；服务商已接受的请求可能仍收费，取消不能保证撤回。
- 保留 alpha.4 的系统返回关闭弹层、连续正文朗读、段落高亮和错误诊断。

云接口仅通过模拟测试，未使用真实账户调用或验证实际音质、账户兼容性、费用。原生播放与网络取消的设备覆盖有限，不能保证服务端取消。请先用不含个人信息的短句测试。系统引擎仍取决于设备已安装的离线中文模型；请求引擎不可用时 Android 可能回退。

下载 InkDock-debug.apk 与 SHA256SUMS.txt。最低 Android 8.0，面向 Android 15。此版本尚未通过 Vivo Y300t 真机验收。

预览包采用临时 debug 签名，可能无法覆盖安装旧版，需要卸载后再安装；卸载将清除文档副本、阅读进度、设置及已保存密钥，请保留原始文档。没有正式发行签名。

限制：8 MiB 单文件、仅保留当前文档、每次40个完整块；原始HTML、外链图片禁用；EPUB/PDF、同步及LLM文本生成未实现。导入阅读本身不上传，只有明确确认的云语音片段会发送到所选服务商。

后台测试采用测试APK内合成TTS引擎验证Android生命周期与控制，不证明真实引擎音质或扬声器出声。新增FOREGROUND_SERVICE、FOREGROUND_SERVICE_MEDIA_PLAYBACK和WAKE_LOCK权限用于用户主动启动的后台媒体播放。
