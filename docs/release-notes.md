# InkDock v0.1.0-alpha.4

本次修复：
- 系统返回先关闭目录/更多/声音弹层，Android 13–15使用原生返回回调；弹层关闭后保留正常返回桌面行为。
- 从当前正文段连续向后朗读并高亮；选中文字只读所选内容。跳过标题、纯公式和代码；长段分片，不静默截去尾部。
- 区分入队、引擎开始、完成和错误；加入错误码/耗时诊断与显式提示，避免把入队成功当作实际出声。进入后台或点停止会取消队列，忽略迟到回调。
- 没有新增 LLM / 云 TTS 配置、网络权限或付费服务。手机实际声音仍依赖系统离线中文引擎、音量和输出设备。

面向 Android 15（包括 Vivo Y300t）的离线 Markdown + LaTeX 阅读 MVP。最低 Android 8.0。

下载 InkDock-debug.apk；SHA256SUMS.txt 可用于校验下载。安装时按系统提示允许浏览器/文件管理器安装此来源应用。此包为调试签名预览版，尚未在 Vivo Y300t 真机上验证。后续预览包可能使用不同调试签名，需要卸载旧版再安装；卸载会清除文档副本和阅读进度，请保留原文件。

支持系统文件选择/分享导入 UTF-8 文本、H1–H6 折叠目录、离线 KaTeX、完整块分组加载、段落进度、字号/夜间、已安装离线中文 TTS 朗读。首次启动有合成示例。没有网络权限，不发送文档。

限制：8 MiB 单文件、仅保留当前文档副本、一次40个完整块；不是完整虚拟滚动；原始 HTML 按文字显示，外链/图片禁用。TTS 支持所选文字或当前正文段连续播放；公式朗读效果取决于系统语音。请从设置下载离线中文语音包。书签/搜索/EPUB/PDF/云同步未实现。
