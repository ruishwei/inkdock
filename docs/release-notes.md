# InkDock v0.1.0-alpha.3

本次改进：
- 取消所有上下划显隐与右滑目录操作，改为轻点正文切换底栏；不再显示「工具」浮动按钮。
- 底栏缩为单排三个图标：目录、朗读/停止、更多。字号、主题、声音和导入收进更多。
- 目录删除重复的「阅读此节」，标题直接跳转，独立箭头展开/收起。
- 系统状态栏/导航栏与正文背景融合，日夜模式切换图标深浅，保留内容安全边距。
- 朗读中图标明确是停止，重播从当前段落起读，不伪装成断点暂停。保留离线音色与语速设置，没有接入云语音。

面向 Android 15（包括 Vivo Y300t）的离线 Markdown + LaTeX 阅读 MVP。最低 Android 8.0。

下载 InkDock-debug.apk；SHA256SUMS.txt 可用于校验下载。安装时按系统提示允许浏览器/文件管理器安装此来源应用。此包为调试签名预览版，尚未在 Vivo Y300t 真机上验证。后续预览包可能使用不同调试签名，需要卸载旧版再安装；卸载会清除文档副本和阅读进度，请保留原文件。

支持系统文件选择/分享导入 UTF-8 文本、H1–H6 折叠目录、离线 KaTeX、完整块分组加载、段落进度、字号/夜间、已安装离线中文 TTS 朗读。首次启动有合成示例。没有网络权限，不发送文档。

限制：8 MiB 单文件、仅保留当前文档副本、一次40个完整块；不是完整虚拟滚动；原始 HTML 按文字显示，外链/图片禁用。TTS 是所选文字或当前段落，不自动连续播放；公式朗读效果取决于系统语音。请从设置下载离线中文语音包。书签/搜索/EPUB/PDF/云同步未实现。
